# Terraform Workflow

This page will describe how generated HCL fits into a normal Terraform workflow.

## Planned Content

- Generate `.tf` files with `react-hcl`.
- Review generated HCL in pull requests.
- Keep secrets out of build-time values.
- Use Terraform variables for runtime values.
- Run `terraform fmt`, `terraform validate`, `terraform plan`, and `terraform apply` with Terraform CLI.

Phase 3 will turn this into a practical workflow guide.
