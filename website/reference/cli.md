# CLI Reference

This page will document the `react-hcl` command line interface.

## Commands

```bash
react-hcl generate <input.(j|t)sx|-> [-o <file>]
react-hcl reverse <input.tf|-> [-o <file>] [--module]
react-hcl init [--refresh]
```
